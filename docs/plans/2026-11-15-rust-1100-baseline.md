# Candy fork Rust 1.100 기준선 상향 — 2026-11-15

## 결정과 범위

사용자가 screenshot-ocr-search·alt-picasa에 이어 이 Candy fork도 같은 Rust 기준으로
올리도록 요청했다. 시작은 `theand-fork` / `4d120487b00949f1f73eb59d5eea00814977466b`,
tracked/untracked 변경 없는 상태다. upstream 병합·rebase·push는 하지 않는다.

| 축 | 이전 | 적용 | 판정 |
|---|---|---|---|
| Rust/Cargo | MSRV 1.95, toolchain 핀 없음, 전역 기본 1.98.1 사용 | pin 1.100.0 / MSRV 1.100 | 사용자 승인에 따른 상향 |
| CI Rust | floating stable | 동일 action SHA + 명시적 1.100.0 | 로컬과 정렬 |
| OS/Swift/edition | macOS 14 / Swift 6 / Rust 2024 | 유지 | 상향 필요 없음 |

MSRV 1.95는 최초 workspace 커밋 `c4c16f2`(2026-10-11)에서 왔다. 이번에는 개인 fork의
빌드 기준을 다른 개인 Rust 제품과 맞추며 Rust 1.95–1.99에서의 빌드 지원은 종료한다.
런타임 OS·제품 동작·패키지 버전은 변경하지 않는다. 전역 rustup default도 유지한다.

## 최소 변경과 검증

- 변경 묶음: 루트 Cargo.toml·rust-toolchain.toml·CI·AGENTS·README·docs/releasing.
  실제 compiler/clippy/fmt 실패가 있을 때만 필요한 호환 수정을 한다.
- 새 기능·의존성·override·구조 변경·범용 상태 관리를 추가하지 않는다.
- Rust workspace fmt/clippy(all targets, -D warnings)/locked test를 실행한다.
- Rust staticlib와 Swift 연결을 검증하기 위해 debug 앱 빌드 → Swift 테스트 → release
  앱 빌드를 실행한다. DMG·앱 설치·GUI 실행·서명/공증 배포는 범위 밖이다.
- 빌드 전 기존 GUI·CLI helper는 모두 minos 14.0이었다. 새 산출물도 각각 측정한다.
- Candy fork의 bundle ID·메뉴바 동작·아이콘·설치 경로는 유지한다.
  `dist/Candy-theand-fork.app`과 그 안의 CLI helper를 실제 제품 산출물로 확인한다.

## 결과

- 실제 프로젝트 rustc `1.100.0 (0ef1bc386 2026-11-09)`, Cargo
  `1.100.0 (3acc79c0c 2026-11-05)` 선택 확인.
- `cargo fmt --all --check`, `cargo clippy --locked --workspace --all-targets -- -D warnings`
  모두 통과. compiler/lint 호환을 위한 제품 소스 수정은 필요하지 않았다.
- `cargo test --locked --workspace`: Rust 테스트 총 72개 통과, 실패·ignored 0개.
- `scripts/build-app.sh --debug` 통과 후 `scripts/swift.sh test`: Swift Testing 24개·
  3개 suite 통과. 별도 XCTest runner의 0건 요약과 구분해 실제 실행을 확인했다.
- `scripts/build-app.sh` release 통과. GUI·CLI helper 모두 arm64·minos 14.0으로 유지됐다.
- 완성된 fork bundle의 strict/deep codesign 검증, `LSUIElement=true`, bundle ID 및
  plist 최소 OS 14.0 보존 확인. helper `candy --version`은 `candy 0.3.2`로 exit 0이다.
- CI YAML 파싱·정확한 Rust input 확인, Cargo.lock은 HEAD와 byte-identical이다.
  패키지 버전·feature·workspace 구성은 바뀌지 않았다.

변경은 기준선·CI·문서뿐이다. fork 브랜치·메뉴바 동작·브랜드·빌드/설치 경로를
유지했다. GUI 수동 조작·다른 Mac·원격 CI·DMG·앱 설치·push는 실행하지 않았다.
소스 빌드가 통과한 것과 실제 설치·GUI 사용 검증은 구분한다.
